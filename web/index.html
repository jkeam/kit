Python only. Define a main(**kwargs) function that returns a string result. Available modules: json, math, re, datetime, time, random, string, itertools, collections, functools, textwrap, hashlib, base64, csv, io, statistics, urllib.parse.

Show example 
def main(**kwargs):
    text = kwargs.get("text", "")

    words = len(text.split())
    lines = text.count("\n") + (1 if text else 0)
    chars = len(text)

    return f"{words} words, {lines} lines, {chars} characters"
