Custom tools are sandboxed Python. Define a main(**kwargs) function that returns a string result. Available modules: json, math, re, datetime, time, random, string, itertools, collections, functools, textwrap, hashlib, base64, csv, io, statistics, urllib.parse.

def main(**kwargs):
    text = kwargs.get("text", "")

    words = len(text.split())
    lines = text.count("\n") + (1 if text else 0)
    chars = len(text)

    return f"{words} words, {lines} lines, {chars} characters"

# Python Best Practices

## Code Style
- Use type hints for all function signatures
- Keep functions under 20 lines
- Prefer list comprehensions over map/filter

## Error Handling
- Catch specific exceptions, never bare except
- Use contextlib.suppress for expected errors
